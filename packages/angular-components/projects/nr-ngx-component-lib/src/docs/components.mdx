# Components

Every component in the NR Angular Component Library, grouped the same way as the sidebar. All of them are
declared and exported by `NrNgxComponentLibModule`.

| `ApplicationComponent` | Application frame holding the header, menu, and page content | [Application](?path=/docs/navigation-and-structure-application--docs) |
| `ApplicationHeaderComponent` | Title bar with the application name and actions | [Application Header](?path=/docs/navigation-and-structure-application-application-header--docs) |
| `ApplicationMenuComponent` | Navigation menu | [Application Menu](?path=/docs/navigation-and-structure-application-application-menu--docs) |
| `PageContainerComponent` | Main content container | [Page Container](?path=/docs/navigation-and-structure-page-container--docs) |

| `TabGroupComponent` | Tabs, in standard and classic styles | [Tabs](?path=/docs/navigation-and-structure-tabs--docs) |
