# Components

Every component in the NR Angular Component Library, grouped the same way as the sidebar. All of them are
declared and exported by `NrNgxComponentLibModule`.

## Foundations

Building blocks used by the other components.

| Component | Description | Docs |
|-----------|-------------|------|
| `IconComponent` | Material Symbols and the library's custom icons | [Icon](?path=/docs/foundations-icon--docs) |
| `GapComponent` | Spacing between elements | [Gap](?path=/docs/foundations-gap--docs) |
| `TooltipDirective` | Tooltip on any element | [Tooltip](?path=/story/foundations-tooltip--primary) |
| `DeviceViewComponent` | Shows different content on desktop and mobile | [Device View](?path=/docs/foundations-device-view--docs) |
