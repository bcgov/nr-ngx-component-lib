# Icon

`<nrcl-icon>` shows an icon by name. The name can be a
[Material Symbols](https://fonts.google.com/icons) icon, or one of the library's own SVG icons. Interactive
examples are under [Examples](#examples).

`IconComponent` is declared and exported by `NrNgxComponentLibModule`, and `IconService` is exported by the
library. Material Symbols icons need the Material Symbols Outlined font, loaded as in
[Load the icon font](?path=/docs/introduction-getting-started--docs#3-load-the-icon-font).

## Usage

```html
<nrcl-icon>warning</nrcl-icon>
<nrcl-icon small>check_circle</nrcl-icon>
<nrcl-icon large [fill]="false">info</nrcl-icon>
```

Put the icon name inside the element. The other library components that take an icon name, such as
[buttons](?path=/docs/inputs-and-controls-button--docs), show it with `<nrcl-icon>`, so these names work
there too.

**The name is read once**, when the icon is created. To change the icon, change the element itself, for
example with `@if`, rather than changing the text inside it.

## Names

The library's own icons are used first. Any other name is shown with the Material Symbols font.

The library's icons are `clear-filters` (used by the filters panel's Clear button), `home-outline`,
`mcp-server`, `roster`, and `user-clock`, all shown under [All icons](#all-icons). There are also two
special names:

| Name | Shows |
|------|-------|
| `empty` | A blank space the size of an icon. |
| `__missing__` | A box with a question mark. Shown when the icon settings after the name can't be read. |

### Adding icons

Add your own SVG icons with `IconService.defineIcon()`, for example in your root component's constructor:

```typescript
import { IconService } from '@bcgov/nr-ngx-component-lib';

constructor() {
    inject( IconService ).defineIcon( 'helicopter', `<svg viewBox="0 0 24 24">...</svg>` );
}
```

- Names may only use lower-case letters, digits, `-`, and `_`.
- A name that's already defined is replaced, with a warning in the console.
- The SVG is inserted as it is, without being sanitised, so only use SVG from a source you trust.
- Give the SVG a `viewBox` and no fixed `width` or `height`, so it fits the icon size. Paths are filled in
  the text colour, `currentColor`.

## Size and fill

| Attribute | Size |
|-----------|------|
| `small` | 18px |
| none | 24px |
| `large` | 30px |

Material Symbols icons are filled by default. Set `[fill]="false"` for the outlined version. `fill` has no
effect on the library's SVG icons.

The settings can also go after the name, as JSON, which helps where an icon name is passed as a string, such
as to a button:

```html
<nrcl-button label="Info" icon='info;{"fill":false,"small":true}'></nrcl-button>
```

## Inputs

| Input | Type | Default | Description |
|-------|------|---------|-------------|
| `small` | `boolean` | `false` | 18px. |
| `large` | `boolean` | `false` | 30px. |
| `fill` | `boolean` | `true` | Filled Material Symbols icon. |

## Styling

The icon takes the text colour. Change the sizes with these properties:

| Property | Default |
|----------|---------|
| `--nrcl-icon-small-size` | 18px |
| `--nrcl-icon-normal-size` | 24px |
| `--nrcl-icon-large-size` | 30px |
